# 原型 1 结论：免费 A 股行情接口可行性

## 验证时间
2026-11-26（Asia/Shanghai）

## 验证目标
验证 ADR-0002 中“免费渠道优先（东方财富/新浪财经）”获取 A 股日线行情的可行性。

## 验证方法
- 脚本：prototype_stock_quotes.py（一次性原型，可直接运行）
- 接口：东方财富 push2.eastmoney.com、新浪财经 hq.sinajs.cn
- 样本：贵州茅台(600519)、宁德时代(300750)、上证指数(000001)

## 验证结果（当前环境）
- 东方财富：**首次请求成功**（HTTP 200，延迟 333~489ms，返回 12 个字段）
- 重复请求：**被限流**（RemoteDisconnected），短时间内多次请求会被拒绝
- 新浪财经：未成功（同网络限制）
- 结论：接口本身可用，当前 IP 受临时限流；T+1 每日一次抓取不受影响

## 建议下一步
1. 在 IP 限制解除后，重跑 python prototype_stock_quotes.py 确认字段映射无误。
2. 行情抓取代码做 adapter 抽象层，支持东方财富/新浪/腾讯多源切换。
3. T+1 收盘后抓取，每天一次，避免频率限制。
4. 将实测结果回填到 ADR-0002。
