# ADR-0008：公共导入脱敏与全市场收盘采集

状态：已接受（2026-11-28，用户授权继续补公共导入脱敏、全市场采集及逐条验收清单）。历史备用由ADR-0009/0010补充，全目录快照优先与逐只补采保存由ADR-0011补充。

## 公共导入

`/upload` 与个人策略采用相同的文本脱敏规则。文字在第一次写入任务文件前脱敏，PDF 解析后的正文在切分、模型调用和向量化前脱敏，主体名称的模型输出也再次脱敏。每次上传使用随机私有临时目录，服务端固定文件名，拒绝空文件、超限、无效 PDF 和非 UTF-8 文字；成功和失败都清理本次目录。

原件、PDF 解析图片与 ZIP 不备份到 MinIO，正文中的图片引用省略，新公共上传只索引文本。既有产品文档的文本问答、混合检索、重排、SSE 与旧公共 schema 兼容保持；既有图片索引不自动删除。图像像素尚无可靠脱敏能力，因此不继续自动发布新上传原图。导入页展示这一行为。

该决策替代 ADR-0006 中“MinIO 存策略 PDF”的提议，优先落实 ADR-0005。MinIO 保留用于原有已入库资产；不自动删除用户历史文件。PDF 原件在解析期间会暂存并发送至已配置 MinerU，远端保留时间由服务提供方决定；本地进程强制终止也可能留下临时文件，不能把正常清理称为原件从未出现或保证永久无残留。

## 全市场采集

- 在查询服务内增加独立收盘任务，Asia/Shanghai 工作日 16:00 执行。与 15:30 每日摘要独立，摘要继续以关注股票和双指数组织内容。
- 东方财富分页读取证券目录，核对总数、每页长度、代码唯一性、市场标识；失败尝试新浪完整分页目录。名录不等于真实目标日行情，备用目录不被标记为完整市场覆盖。
- 源目录可能混入转债、历史代码和退市证券。完整分页后筛选支持的沪深股票和北交所现行 `920` 股票代码，保留源总数和排除代码；出现无法识别代码时明确降低覆盖状态。补入实测存在的 `302132` 代码前缀支持。
- 腾讯每批最多50只获取快照，复用已有字段单位和日期解析；核验每只的市场、代码、名称与收盘时间。名称仅做空白与全角归一化，保留 ST 等标记。缺失尝试东方财富目标日日线，受全局预算、每请求重试上限与源冷却约束；不把无日期列表价格当作收盘记录。
- MongoDB 继续按 `(code,date)` 幂等保存。持久记录总数、成功、缺失、排除与来源；`completed` 仅表示该主源目录内全部支持证券均已保存且无目录排除，仍不是交易所全集认证。`partial` 或 `failed` 不冒充全市场成功。
- 180秒租约、30秒心跳、随机 token 保护状态发布，数据库级全局锁限制跨日期并行采集。本进程最多一个 worker，20分钟预算，停止、来源故障和超时保留已保存行情；重试重新核对目录并跳过目标日已有行情。
- 单日手动采集和进度查询可在页面完成。盘中、周末和未来日期拒绝；节假日须由实际目标日行情核验，无法取得时失败。历史补采只保存来源仍能提供的实际历史数据，不承诺完整历史补库。

## 验收

验证公共 PDF/Markdown 上传、模型输入与写库脱敏、原件/图片不备份、失败清理、非法请求不回显；复验真实 PDF、旧 schema 和公共知识 RAG。行情验证完整分页、重复与异常目录、批量日期/身份/单位、北交所核验、部分成功、续跑、租约过期、调度与接口，并在独立测试集合执行真实全市场抓取。长期连续交易日稳定性与免费来源完整性需单独观察，不能由一次成功推断。
