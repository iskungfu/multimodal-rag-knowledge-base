# ADR-0007：个人使用版补齐

状态：已接受（2026-11-28 用户确认本轮范围）。

## 决策

- 每日投资摘要增加公共知识引用；共享现有公共检索的归属校验，公共知识不足或失败明确提示，不能冒充个人策略或行情。
- 用户档案保存自述风险偏好、投资期限、偏好板块和补充文字；用于检索与提示，不修改行情规则等级，也不是风险承受能力测评。
- 策略模式是用户命名的一组已完成导入的个人策略文档，可创建、修改、删除和选择；默认使用全部个人策略。明确选择空模式时不回退到其他策略。切换仅影响后续问答和新生成摘要，已有回答与摘要保持历史内容。
- MongoDB 单文档存储档案、模式与当前选择，revision 防止并发覆盖；Milvus 不改变 schema，在向量检索前限制文档编号，并在检索后复核。
- 复盘通过编辑自然语言原文纠错，再自动抽取和索引。原文更新先落库，同时使旧索引不可引用；revision 与请求编号防止旧抽取任务覆盖和重复提交。模型失败仍保留新原文。无需逐字段填写交易表单。
- 保持单用户、原 HTML 页面和双服务架构，不引入券商、多用户认证、审计或自动交易。

## 与既有决策的关系

补充 ADR-0003 的策略资料组织及人工纠错，不把文档变成可执行策略或回测模型；沿用 ADR-0005 的双端脱敏和 ADR-0006 的单用户架构。

## 验收

验证公共知识引用真实性和隔离、模式切换在摘要与问答中生效、偏好不改行情、纠错时旧索引立即不可见、并发与失败恢复、表单保留输入及移动端布局；最后执行真实 RAG 回归。
