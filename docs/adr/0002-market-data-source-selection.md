# ADR-0002: A 股行情数据源与存储选型

## 状态
已提议

## 背景
个人投资顾问平台需要 A 股实时/每日行情数据，用于大盘趋势判断、个股风险评估、个性化投资助手等模块。原项目技术栈包含 FastAPI、Milvus、MongoDB、MinIO，需在此基础上选型行情数据源和存储方式。

## 决策
### 数据源
**免费渠道优先**：
- 东方财富行情接口（免费，覆盖沪深 A 股全部个股及指数）
- 新浪财经 / 腾讯财经（作为备用源，防止单点失效）
- 部署上线推广后，再切换为付费专业行情 API（如聚宽、优勤、Wind 等）

**更新频率**：
- 默认在交易日收盘后更新当日行情，次日可查看；不是延迟到下一交易日才采集
- 预留实时行情接口，未来如需盘中行情可通过轮询或 WebSocket 扩展

**目标覆盖字段**（正式实现时逐项验证）：
- 代码、名称、当前价、涨跌幅、成交量、成交额、换手率、市盈率（PE）、最高价、最低价、开盘价、昨收价
- **单位与编码**：原型中的字段映射、缩放和强制 gbk 解码未经充分验证，不能直接作为实现规范。按具体接口及响应精度元数据验证，保留原始样本；历史日线和实时快照分开适配。
- **可用性**：原型仅有少量快照成功，后续出现 RemoteDisconnected；原因未确认，不能认定每天请求一次就一定成功，也不能据此认定全市场和历史日线已验证。

**架构建议**：行情抓取做 adapter 抽象层，支持东方财富/新浪/腾讯多源切换，避免单源限流导致抓取失败。

### 存储
**复用现有基础设施**：
- 行情时序数据存入现有 MongoDB 的新集合 market_quotes
- 文档结构：{ code, name, date, close, change_pct, volume, amount, turnover, pe, pb, market_cap, updated_at }
- 建立 (code, date) 联合唯一索引，支持按股票代码+日期查询，以及按日期范围查询大盘趋势

**不新增专属时序数据库**：
- 现有 MongoDB 足够承载 A 股约 5000 只股票的日线数据，数据量不大，无需引入 InfluxDB/TDengine 等新组件

## 替代方案
- **付费专业行情 API 作为首选**：被否决。项目尚未商业化，免费渠道足以满足原型开发和个人使用需求，付费源增加成本。
- **引入 InfluxDB 存储行情时序**：被否决。A 股日线数据量小，MongoDB 已可胜任，引入新组件增加运维复杂度。
- **不存储行情，每次实时调用 API**：被否决。免费接口有频率限制，且无法离线回测和大盘趋势回溯，存储后更灵活。

## 后果
### 正面
- 零成本启动，符合“先免费、后付费”的产品节奏。
- 复用现有 MongoDB，无新增运维组件。
- 存储历史行情，支持大盘趋势回溯和个股风险评估的指标计算。

### 负面/风险
- 免费行情接口可能有访问频率限制、稳定性不足或突然变更，需做重试和备用源切换。
- 免费数据的更新时点和延迟需按来源实测，记录数据日期与抓取时间，不将旧数据冒充最新收盘数据。
- 需自行实现数据清洗和去重逻辑。
