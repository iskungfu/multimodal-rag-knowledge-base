# ADR-0009：免费历史日线备用与成交量单位核验

状态：已接受（2026-11-28，用户要求参考开源金融平台接口并推进改进）。

## 背景

ADR-0002、ADR-0008 已采用免费多源，但东方财富日线失败时只能退到腾讯最新快照，历史补采没有第二条日线渠道。参考项目和真实样本见 `docs/market-source-research.md`。

## 决策

1. 新增 `TencentHistoryAdapter`，单股位于东方财富日线之后、腾讯快照之前；全市场缺失项在东方财富目标日补采失败后尝试腾讯历史日线。继续复用 requests、MongoDB、原API和现有预算，不新增SDK或付费token。
2. 只读取不复权 `day`，校验证券键、代码、名称、日期范围、OHLC、重复日期和640条截断；来源不可用走下一适配器。腾讯两类接口不被视为两家独立供应商。
3. 腾讯688/689成交量原本就是股，其余支持股票的手数乘100。成交额字段8由万元换算为元；换手率字段7保持百分数。历史日线与最新快照同时修正，并记录原始单位乘数。
4. 日线没有可核实的历史涨跌幅与动态PE时保留空值。只有同日同OHLC同量的收盘快照可以补充当日指标；不借用当前估值或从不复权价差猜测收益，风险评级继续降级。
5. 对缺少正确单位标记的旧腾讯科创板记录，读取时用原始快照核验并恢复成交量；无法核验时将返回成交量置空。保留数据库原文，禁止无证据批量乘除100。单股刷新仍可保存重新抓取的有效行情。

## 后果与范围

历史补采增加了实际可用路径，但免费源可暂时不可用、证券更名可能导致身份核验失败，仍允许partial/failed。历史日线的字段缺失不会因为增加适配器而消失。全市场目录、指数专用适配、用户策略、RAG和风控阈值不在本轮修改范围。

后续可独立实测BaoStock或Pytdx；不因其他项目宣称支持而直接启用。数据再分发和商业部署是后续单独事项。
