# ADR-0004: 个股风险评估与大盘趋势

## 状态
已接受；正式实现见 `docs/stock-risk.md` 与 `docs/daily-summary.md`。

## 背景
平台需要为普通投资者提供个股风险等级和大盘当前位置风险，供查询个股和每日投资摘要参考。数据来源于 ADR-0002 落地的 A 股行情引擎（交易日当天收盘后更新，存入 MongoDB market_quotes）。

## 决策
### 风险指标：全部自动获取，无需用户输入
个股风险评估基于行情引擎已有字段自动计算，用户无需手动录入任何指标：
- 涨跌幅（当日）
- 换手率
- 近 N 日波动率（标准差）
- 市盈率 PE
- 成交量异常（当日量比近 N 日平均量）

输出为三档：低风险 / 中风险 / 高风险。普通投资者只需看到“高风险”这样的结论，无需理解底层计算。

### 大盘趋势：不给出牛熊/震荡阶段判断
不输出“牛市/熊市/震荡”这类阶段性市场判断，因为牛熊转换不是一天两天，此类判断容易误导。仅输出“大盘当前位置风险（高/中/低）”，帮助投资者判断当前买入时点的风险程度，而非预测市场阶段。

大盘位置风险基于上证指数/深证成指的近 N 日涨跌幅、成交量变化自动计算。

### 触发时机与展示方式
- **用户查询个股时**：在按需查询回答中，自动附带该个股的风险等级（低/中/高）。
- **每日投资摘要**：将个股风险等级和大盘位置风险融入摘要内容，例如“你关注的 XX 股今日风险为高，大盘位置风险也较高，建议谨慎追高”。
- **不单独设置风险提示模块或单独推送风险预警**，避免信息过载。

## 替代方案
- **用户手动输入风险指标**：被否决。行情引擎已自动获取所有所需字段，强迫用户手动输入增加录入门槛且容易出错。
- **输出牛熊/震荡市场判断**：被否决。牛熊转换周期长，此类判断不稳定，且容易被误解为投资建议，增加合规风险。
- **单独推送每日风险预警**：被否决。普通投资者信息已较多，风险信息应在查询个股和每日摘要中按需消费，不做独立推送。

## 后果
### 正面
- 零用户输入成本，完全自动化。
- 风险等级直接嵌入现有查询和摘要流程，无需新增 UI 入口。
- 三档风险等级对普通投资者友好，避免专业术语过载。

### 负面/风险
- 风险等级基于历史行情指标计算，是滞后指标，不能预测突发风险（如突发负面消息、退市风险等）。
- PE、波动率等指标在不同行业间不可直接横向比较，需在展示时注明“仅供参考”。
- 免责声明仍需强制展示，避免用户将风险等级视为投资建议。
