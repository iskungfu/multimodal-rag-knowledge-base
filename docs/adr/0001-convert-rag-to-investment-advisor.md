# ADR-0001: 将通用 RAG 知识库转型为个人投资顾问平台

## 状态
已接受；个人使用版实现与范围见 ADR-0007、ADR-0008 及 `docs/requirements-acceptance.md`。

## 背景
原项目是一个通用的 RAG 知识库问答系统，支持 PDF/Markdown 文档上传、向量检索、重排序和流式对话。产品方向需要转型为面向普通投资者的个人投资顾问平台，核心能力包括 A 股实时行情、大盘/个股风险评估、经典投资书籍知识库 RAG，以及用户可自定义的个性化交易策略助手。

## 决策
在现有 RAG 架构基础上，新增以下模块：
1. **A 股行情引擎**：每日获取沪深 A 股行情数据，支持大盘趋势和个股风险评估。
2. **用户档案与策略模式**：存储用户的交易风格、偏好板块、买卖点条件、复盘策略、牛熊市把握方法。
3. **个性化投资助手**：结合用户档案、实时行情和知识库 RAG，给出个性化投资提示。
4. **脱敏层**：对姓名、手机号、身份证号、银行卡号、持仓金额等敏感字段自动脱敏。
5. **免责声明**：所有投资建议强制附加“不构成投资建议，投资有风险，入市需谨慎”。

保留现有能力：BGE-M3 向量检索、BGE-Reranker 重排序、SSE 流式对话、FastAPI 后端、Milvus 向量库、MongoDB 文档库、MinIO 对象存储。

## 替代方案
- **完全重构**：推翻现有代码重新开发。被否决，因现有 RAG 基础设施（检索、重排序、流式对话）可直接复用，重构成本过高。
- **仅增加行情模块，不加用户策略**：被否决，因个性化交易策略是平台差异化核心，普通投资者需要与自身风格匹配的建议。

## 后果
### 正面
- 现有 RAG 检索管道可直接复用，开发成本低。
- 知识库 RAG 为投资建议提供经典理论依据，提升可信度。
- 个性化策略模式满足不同投资者的差异化需求。

### 负面/风险
- 引入外部行情数据源，增加对第三方 API 的依赖和稳定性风险。
- 个股风险评估和投资建议涉及合规风险，必须配合严格的免责声明和脱敏机制。
- 用户输入的交易记录和持仓信息属于敏感金融数据，需要额外的安全保护。
