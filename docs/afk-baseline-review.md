- 行情原型仅测试了少量快照；字段公式、编码、历史日线、全市场覆盖及请求频率稳定性尚未验收。旧 Issue #2 的固定公式不能作为权威期望，实现时以核实后的样本和接口行为为准。

- 本地规范与旧 Issue 的原型断言冲突时，遵循这里及更新后的 ADR/spec；在任务结果记录验证证据与差异。
