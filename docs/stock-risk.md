# 个股风险按需查询（Issue #5）

在现有 `/chat.html` 输入 `平安银行（000001）的风险如何？`、`贵州茅台能买吗？` 或完整六位代码，即可通过原有 `POST /query` 获取风险。非流式、SSE、任务状态及历史使用同一份服务端终稿。没有新增独立风险页面、交易接口或定时任务。

## 身份与路由

- 使用东方财富公开证券检索 `https://searchapi.eastmoney.com/api/suggest/get`（`input/type=14/count=20`），只接受 `Classify=AStock`、沪深代码前缀、`MktNum` 和 `QuoteID` 一致的记录。代码与来源精确匹配，名称必须在用户文本中完整出现；简称只给核实后的候选，请用户确认，不猜代码。名称与行情名称再次核对。
- `000001` 仅作为 `sz000001` 平安银行。指数、基金、市场前缀错误和名称代码冲突不自动改写。订单、邮编、验证码及普通产品问题不会因含六位数字而成为股票查询。
- 校验每个 `sh/sz` 前缀与 `.SH/.SZ` 后缀，先检查市场再对代码去重；混写 `sz000001` 与 `sh000001` 也要求确认。允许代码后带普通问题描述，但已核实的名称/简称候选与代码冲突时仍要求确认；常见口语引导词会先剥离再核实名称。
- 用有限的常见中文问句规则切出用户明示名称；不承诺理解所有简称、历史更名或复杂多证券句式。无法核实则要求完整名称/代码，用户无需填写行情指标。不用 LLM 做证券身份猜测。
- 证券检索复用行情层的串行限速、有界重试及失败冷却，成功/空结果缓存 1 小时，最多 512 项。只发送切出的查询词，先执行输入脱敏，不发送完整交易日记。
- 个股走行情与规则服务，跳过商品确认；公共知识问题保留 LangGraph 的向量检索、HyDE、RRF、rerank 和回答生成，按既有 `doc_type=knowledge` 隔离，不强制商品名过滤，也不调用商品网络搜索。明确产品问题保留原商品确认及 RAG。后续 #7 已接入个人策略/公共知识/复盘三路召回，见 `docs/personalized-investment-assistant.md`。
- 指数基金的知识解释可进入公共知识检索，具体指数/基金评级仍不支持。设备追问保留原商品流程，非金融问题不会因为证券源故障而被当作证券核验失败。

## 行情与规则 v1

每次个股查询请求最近 120 个自然日的已收盘行情；同区间复用 #2 的 300 秒缓存。按日期排序，完全相同的重复日期只算一次，冲突日期不参与计算；最新日冲突则拒绝评级。实际行情日期、来源、动态 PE 来源、抓取时间（含时区）、可得的源快照时间及距查询日的自然日数一起展示。自然日差不是交易日延迟；休市、停牌或源延迟不能仅靠本地日期分辨。

所有数值来自行情，不要求用户输入。价格为元、成交量为股、涨跌幅和换手率为百分数、PE 和量比为倍。

| 指标 | 计算 | 中档起点（含） | 高档起点（含） |
| --- | --- | --- | --- |
| 日涨跌幅 | 来源当日 `change_pct` 的绝对值 | 5% | 9% |
| 换手率 | 当日 `turnover` | 5% | 15% |
| 20 日波动率 | 最新 20 条不同日期日线的来源日涨跌幅**样本标准差**（ddof=1，不年化） | 2% | 4% |
| 动态 PE | 最新日 `pe`，仅使用该日可核实估值 | 40 倍 | 80 倍 |
| 成交量比 | 当日成交量 / **此前** 20 条不同日期日线平均成交量，不含当日 | 2 倍 | 3 倍 |

补充规则：动态 PE ≤0 按估值异常高风险处理，不解释为低估；量比 ≤0.2 为中档，量比为零为高档。均量为零则量比缺失，禁止除零。负换手率、负成交量、NaN/Infinity 及非数值视为缺失；历史窗口内无效字段不会用更老记录凑数。

**聚合为各指标最高档**，不做加权或总分。边界比较容忍 1e-12 的相对/绝对浮点误差，防止标准差在数学边界因舍入而降档。五项齐全且有效、日期可用、更新成功时，全部低于中档阈值才给低风险。有缺失时，如果已观察到中/高档，只给明确标注“有限依据”的中/高风险；其余情况为“无法完整评估”。后者表示拒绝评级，不是新增一个风险档。

历史日线不提供历史 PE 属于预期，不影响已核实的最新日 PE。腾讯备用只有快照时明确列出波动率和量比缺失。更新失败可以使用已存行情，但说明旧缓存及实际日期，不能给当前低风险；缓存也不可用时明确拒绝评估。不从不复权收盘价反推跨日收益率，避免除权价阶跃污染源日涨跌幅。

这些阈值是可解释的初始规则，未经回测，不预测涨跌；不同板块、行业、上市初期及停牌情形不具备统一统计校准。大盘位置风险已由后续模块实现，见 `docs/daily-summary.md`；仍不做市场阶段分类。

## 回答边界

`QueryService` 在图/风险查询结束后统一完成答案脱敏、免责声明去重、历史写入、任务结果和 SSE 发布。模型的逐 token 输出先缓冲完整文本，避免号码、姓名、金额或表格跨 chunk 绕过脱敏；SSE 保留进度事件，答案以一个完整安全 delta 和一个相同 final 发出，final 后不再有 progress。代价是答案文字在生成完毕后才显示。

固定尾句：`以上信息不构成投资建议，投资有风险，入市需谨慎。` 商品确认、无结果、异常回答同样覆盖。输入、重写查询、实体名称、回答在会话持久化及返回时复用现有规则脱敏；旧历史读取时也补齐政策，但不批量改写旧数据。历史保存失败返回明确错误；底层异常原文不返回。前端图片解析保留图片块之后的免责声明。

仅保护当前检索结果实际包含的 `[chunk_id=...]` 标识，白名单随服务端任务及会话保存，确保长数字 ID 不会被误当敏感号码改写。模型自行编造的标识没有该豁免。历史记录以 `ts` 和 `_id` 排序，避免 Windows 上连续写入时间戳相同时问答颠倒。阈值说明直接使用评级常量，避免解释与实际计算不一致。
