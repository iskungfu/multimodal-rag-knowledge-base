# 原型 3 结论：三路召回效果验证

## 验证时间
2026-11-26（Asia/Shanghai）

## 验证目标
验证 ADR-0003 中“三路召回（个人策略 + 公共知识库 + 行情数据）→ LLM 融合生成个性化投资建议”的效果。

## 验证方法
- 脚本：prototype_three_way_retrieval.py
- 模型：本地 group/group（http://127.0.0.1:3425/v1）
- 3 组查询：1）今天贵州茅台适合买吗？ 2）大盘见顶了怎么调整仓位？ 3）RSI 超卖时买入点可靠吗？
- 三路召回数据：个人策略（用户心得）、公共知识（《聪明的投资者》《股市真规则》）、行情（模拟 A 股行情）

## 验证结果
- 三路信息均被正确引用，未出现来源幻觉。
- 建议具有个性化（结合个人轻仓龙头策略）和时效性（结合当日 PE、涨跌幅、大盘点位）。
- 所有回答结尾均有免责声明。
- 结论更正（2026-11-27）：仅验证了手工拼接上下文后的文本生成，未执行真实检索、RRF 或 rerank，不能据此验收召回质量。

## 对 ADR-0003 的影响
- 保持“三路召回 + RRF 融合”设计不变。
- 后续实现时需确保 Milvus 的 `personal`/`knowledge`/`review` 三类文档能按 `owner_id` + `doc_type` 正确过滤；行情单独作为结构化上下文补充。
