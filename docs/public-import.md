# 公共文档导入

导入页选择“通用知识文档”，支持 PDF、Markdown、UTF-8文字，最大50 MB。`POST /upload` 保持返回 `task_id`，`GET /status/{task_id}` 查询进度及固定错误提示；接收成功不等于处理完成。

## 保存与隐私

文字在写临时文件前脱敏；PDF正文在 MinerU 解析后、切分与模型调用前脱敏。主体名称模型输出再次脱敏。沿用 ADR-0005 的简易规则：手机、身份证、银行卡、带标签姓名及持仓/交易总金额；单价和策略条件保留。不承诺识别所有自由文本姓名或任意编码的隐私。

原始文件、原始图片及 ZIP 不进入 MinIO；新公共知识只保存脱敏文本切片和索引。图片引用省略，不从原图生成公开链接。旧公共 schema、产品文本问答、RRF、reranker、SSE和历史引用继续兼容。

原件仅暂存在随机 `shopkeeper-public-<task_id>-*` 任务目录，文件名固定为 `input.pdf` / `input.md`。PDF 原件必须发送至已配置解析服务，无法宣称发送前像素已脱敏；远端留存由该服务决定。正常成功和失败均删除本次本地目录。强制结束进程可能留下文件，需先确认任务停止再清理；应用不会删除任意路径。

本次修改只约束新导入，不批量改写历史 Milvus 记录或删除原有 MinIO 备份。含私人信息的历史原件需要单独盘点并由用户决定保留、重新导入或删除。

## 失败与重试

- 空文件、无效 PDF、非 UTF-8文字、超过50 MB返回422，不把失败伪装成接受成功。
- 暂存失败返回503；解析/嵌入/存储失败以任务 `failed` 返回，错误不包含原始正文、文件名或连接凭据。
- 临时目录清理失败同样显示 `failed`。重试是新上传任务；原公共流程未新增事务式整文档回滚或导入历史队列。
- 前端保留本次文件供重试，重新选择文件不会要求手动填写结构化资料。

测试入口：`knowledge/test/strategy/test_public_privacy.py`；真实完整回归入口：`scripts/verify_rag.py --pdf --stream`、`--legacy` 和 `--knowledge --stream`。真实探针必须使用独立 `AFK_TEST_DB_NAME`，不向业务库写入测试资料。
